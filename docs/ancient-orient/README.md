## 掲載する範囲

参照専用の `sources/01_オリエント・インドの古代文明` にある第1〜3回の3ファイルから、各節の本文161段落を抽出した。`source-selection.json` に原文ファイル、内容識別値、行番号、紙面番号、見出し、書き起こしと表示文字列を記録する。空行以外の全行は、掲載する本文または理由付きの省略行のどちらかに一度だけ分類する。

既存の第6章と同じく、章扉、各回の導入の見取り図、クローズアップ、独立した比較表・合否の分かれ目、図表・地図内の文字、吹き出し、＋αの欄外補足、年号のツボ、次回予告は掲載しない。

「アッシリアとアケメネス朝を比べてみよう！」「ササン朝時代の文化をまとめておこう！」など、通常の本文として続く比較・整理の説明は残す。宗教の成立や仏教の展開、南インド諸王朝も各節の本文であり、省略しない。p.26の文化の説明は掲載し、p.27の比較表・年号欄は省く。原文にある表・紙面番号への参照も文章の一部として保持する。

## 文章と装飾

文章の言い換えや誤記の推定修正は行わない。句読点、括弧、記号、書き起こしに含まれる絵文字も原文どおりとする。太字の指定 `**` は表示用の黒太字へ変換し、文字列としては除く。第1章では原画像の装飾を新たに読み取っていないため、赤太字や読み仮名を推定で追加しない。

紙面をまたぐ文章はつないでから文の切れ目でページ分割する。例えばp.19〜20の「これまであ／ったシュメール法」、p.41〜42の「ペルシ／ア湾」、p.57〜58の「ヴ／ァーカータカ朝」を一続きに扱う。p.21の上部はメソポタミアの続き、p.61の上部は北インドの続きであり、紙面上部の柱だけを根拠に次の節へ移さない。

`page-plan.json` は各表示ページと原文段落の開始・終了位置を記録する。原文段落をページの順に結合すると、太字指定を除いた書き起こし本文と完全に一致する。

## 地図

`public/ancient-geography.js` は第1章の地名・王朝・人物・建物の名称と位置を定義する。都市は遺跡・現在地、王朝と人物は本文に関係する拠点、地域は代表位置を示す。人物の印は肖像ではなく、建物も復元図ではない。神名・宗教・身分制度などは所在地の点に置き換えない。「チャンドラグプタ」と「チャンドラグプタ1世・2世」を区別し、「インドラ」の一部を「インド」として表示しない。

海岸線と湖は既存の `ottoman-world-map.svg`（Natural Earth）を共用する。日本など基図の東端を越える説明にも対応するため世界基図を使う。共通描画へ投影を渡しても、`public/map-camera.js` の拡大上限（東西32度・南北24度）を適用する。大河の流路、征服・移動・交易の経路は説明用の概略であり、厳密な行軍経路・河道や国境を表すものではない。移動経路は原文段落と結び付け、同じ表示ページに両端を説明する語があるときに描く。

位置の確認に使った資料：

- [モエンジョ＝ダーロ（UNESCO）](https://whc.unesco.org/en/list/138)：インダス川下流の遺跡と座標。
- [ペルセポリス（UNESCO）](https://whc.unesco.org/en/list/114)：遺跡と座標。
- [サーンチー（UNESCO）](https://whc.unesco.org/en/list/524)、[ナーランダー（UNESCO）](https://whc.unesco.org/en/list/1502)：仏教遺跡の所在地。
- [アッシリア中核地域（ロンドン大学・Oracc）](https://oracc.museum.upenn.edu/saao/aebp/essentials/countries/centralassyria/index.html)：アッシュル・ニネヴェ・アルベラの位置関係。

原文のp.42には「エジプトのアクスム王国」という記述がある。本文は変更せず、地図のアクスム王国はエチオピア北部のアクスムを代表位置として表示する。原文中の説明・年代を校訂する作業は本追加の対象外とする。

## 再生成と検査

- `node scripts/capture-ancient-source.mjs`：確認済みの掲載行を原文から対応記録へ保存する。原文は読み取りのみ。通常の再生成では実行不要。
- `npm run build:source`：保存した対応記録から両章の表示本文を再生成。第1章の入口12本と一覧も更新する。
- `npm run check`：第1章の本文・掲載順・省略範囲・地図・参照先、既存章の検査、全原文ファイルの非改変を照合する。
- `npm run build`：原文ファイルが置かれていない公開環境でも、管理対象の対応記録を使って検査する。
- `npm run check:ancient:browser`：第1章全182ページを幅1280・390で開き、本文・太字・地図名・重なり・はみ出し・拡大上限を検査する。前後移動、番号指定、再読込、次の教材への移動、通常の再生・押し直し、明暗の画面も確認する。
- `npm run check:source:browser`：両章の全337ページについて、大小2画面幅で本文と装飾を照合する。
- `npm run check:browser`：第6章の全155ページの地図表示を確認する。
- `node scripts/check-chapter-navigation-browser.mjs`：全21教材の一覧・入口・章内目次と、従来の転送先・統合箇所を確認する。

すべての画面検査で、教材を開く前に読み上げを停止し、音声を再生しない。
