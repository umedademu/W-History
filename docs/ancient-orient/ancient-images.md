# 古代オリエント・インド文明の人物・建物・道具の画像と演出

v0.071（2026年9月）。内蔵の画像生成機能を使用して生成したスプライトアトラスから切り出し、透過処理を行ったドット絵画像を配備。

## 保存先

すべて `public/images/ancient/` に保存。人物は128×192画素、建物・道具・乗り物は192×192画素の透過PNG。
生成した画像集を升目ごとに切り出し、背景透過処理と最近傍方式による縮小を行っています。生成された透明度を維持しており、外部通信を行わずにローカル完結で動作します。

## アニメーション演出仕様

1. **移動ルート連動（`route`）**:
   - 遠征や交易、布教のルートを持つ場面（例：フェニキア・ギリシアの植民活動、アレクサンドロス東征、アショーカ王の仏教伝道、法顕・玄奘のインド巡礼など）では、アクターが地図上の経路に沿って滑らかに移動します。
2. **対決・争い演出（`versus`）**:
   - カデシュの戦い（エジプト vs ヒッタイト）、テルモピュライ・マラソンの戦い（ペルシア vs ギリシア）、イッソス・ガウガメラの戦い（アレクサンドロス vs ダレイオス3世）、エデッサの戦い（シャープール1世 vs ウァレリアヌス）などの主要戦闘シーンでは、両陣営が向き合い対峙・衝突するアニメーションが自動適用されます。
3. **セリフ吹き出し演出（`bubble`）**:
   - ハンムラビ王「目には目を、歯には歯を」、アメンホテプ4世「アテン神のみを崇拝せよ」、ダレイオス1世「駅伝制を整備し帝国を統治せよ」、アショーカ王「ダルマ（法）による政治を行う」、ガウタマ＝シッダールタ「生老病死の苦悩を解く」など、歴史上の重要人物の肉声が吹き出しとして画面上にアニメーション表示されます。
4. **自動オフセット分散**:
   - 同一都市・同一座標に複数のピン、建造物、人物が集中する場合、重なりを防止するために自動的に座標を上下左右へずらすオフセット分散処理が組み込まれています。
