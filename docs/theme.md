# 明暗テーマ

v0.027（2026年9月7日時点）。教材一覧、更新情報、全9教材、見つからないページで共通の明暗テーマを使う。

## 切り替え

各ページのヘッダーに「ダーク」または「ライト」ボタンを表示する。初めて開いたときは端末の明暗設定を使う。ボタンで選んだ後はブラウザー内に保存し、別の教材へ移動したときや次回開いたときにも同じ表示を使う。保存できない環境では、開いているページの間だけ切り替える。

ボタンには現在の状態と切り替え先を読み上げられる説明を付ける。キーボード操作時には輪郭を表示し、スマートフォンでも教材名や戻る操作を圧迫しない大きさにする。

## 暗色時の配色

本文と操作欄は濃い灰緑、文字は淡い灰白を基調にする。教材ごとの強調色は識別できる明るさに調整する。地図は海を青緑、陸地を黄土寄りに分け、海岸線と境界線を中間の明るさで残す。地名の縁取りは背景から分離できる太さに抑え、都・都市・海・国名を色でも区別する。注目地域は彩度と明るさを補い、進軍・相手の進軍・移動・交易は、それぞれ珊瑚色・水色・緑色・黄色で表示する。人物・建物の画像そのものは元の色を保つ。

基図を単純に暗くするだけでは海と陸地の差が失われるため、暗色時だけ明るさ・彩度・明暗差を合わせて調整する。共通広域図、ティムール用地図、オスマン用世界図に同じ考え方を適用し、地図ごとの上書き表示にも共通の文字色と経路色を使う。

`public/theme.js` が初期設定、保存、ボタンを管理し、`public/theme.css` が一覧と教材の共通配色を管理する。全HTMLが両方を読み込むことを `npm run check` で検査する。
