# 明暗テーマ

v0.024（2026年9月7日）。教材一覧、更新情報、全9教材、見つからないページで共通の明暗テーマを使う。

## 切り替え

各ページのヘッダーに「ダーク」または「ライト」ボタンを表示する。初めて開いたときは端末の明暗設定を使う。ボタンで選んだ後はブラウザー内に保存し、別の教材へ移動したときや次回開いたときにも同じ表示を使う。保存できない環境では、開いているページの間だけ切り替える。

ボタンには現在の状態と切り替え先を読み上げられる説明を付ける。キーボード操作時には輪郭を表示し、スマートフォンでも教材名や戻る操作を圧迫しない大きさにする。

## 暗色時の配色

本文と操作欄は濃い灰緑、文字は淡い灰白を基調にする。教材ごとの強調色は識別できる明るさに調整する。地図は基図を暗くし、地名、都、注目地域、進軍線、人物名、吹き出しを別々に読み取れる色へ切り替える。人物・建物の画像そのものは元の色を保つ。

`public/theme.js` が初期設定、保存、ボタンを管理し、`public/theme.css` が一覧と教材の共通配色を管理する。全HTMLが両方を読み込むことを `npm run check` で検査する。
