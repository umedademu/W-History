## 掲載・省略の方針

`source-selection.json` は9冊の原文全3729行について、掲載・省略とその理由、紙面番号、文字列を記録する。原文ファイルの指紋も保存し、参照元の変更を検出する。`sources` 内には一切書き込まない。

通常本文は、歴史的意義の比較・整理や、囲い込み・思想の説明も含めて掲載する。「大きくつかもう」「クローズアップ」「合否の分かれ目」、表・図版内文字・欄外の吹き出し、独立した「＋α」コラム、年号欄とその案内、回の見取り図・結び・次回予告は省略する。「まとめておこう」という言い回しだけを根拠に通常本文を削除しない。例えば、イギリス絶対王政の特徴や三十年戦争の歴史的意義は掲載している。

第29回は「＋α」コラムの直後に新しい見出しなしで通常本文へ戻る箇所がある。108行の独立した補足だけを省略し、110行以後の統領政府と改革の本文は保持した。第30回の自然科学の人物表は省略するが、その直前の自然科学・医学の通常本文はすべて掲載する。

## ページの区切り

`capture-plan.mjs` に、ページを構成する原文行を明示している。`;` は改ページ、`|` は段落、`+` は紙面をまたいで切れた一段落の接続を表す。`capture-source.mjs` が出力する `reading-plan.json` が実際の表示の構成表であり、文字数で自動的に区切らない。

導入だけのページを作らず、導入と説明、原因と結果、結論と補足をまとめる。紙面をまたぐ67段落を接続した。長い一段落を分ける場合も、カルヴァンの「予定説」と「職業倫理」、国王の役割とウォルポール、三十年戦争へのスウェーデン介入とフランス参戦のように、内容が切り替わる文頭を明示した。ハノーヴァー朝の導入は後続の国王の説明と同じページにする。

確認時点の最長ページは675文字。100文字未満の導入だけのページ、800文字以上の長大なページはない。この数値を生成規則には使わず、検査時の再確認の目安としている。

## 地図

都市・戦場は現地の概略地点、王朝・地域は代表地点、人物は記述に関わる活動拠点に配置する。人物の出生地や、その瞬間の厳密な所在地、王朝の国境を示すものではない。同じ都市に関係する人物も、それぞれ本文に現れた名前を表示する。人物・建物は既存の共通記号を使用し、実物の外観を再現した図とはしない。

`entity-audit.json` は地図登録表から逆生成せず、原文の太字と片仮名の固有名詞候補から人手で確認した370件の照合表。通常のページと地図の照合に加え、これらの人物・都市・地域が地図登録から漏れていないか検査する。所在地のない宗教・思想・制度や架空の王プレスター＝ジョンは地理対象にしない。「東インド会社」の語中から国のインドを誤検出しない。

曖昧な名称は以下のように扱う。

- 「ドミニカ」は第22回のエスパニョーラ島の説明では現在のドミニカ共和国側、第27回の七年戦争後の割譲地の説明ではドミニカ島。同名でもページごとの地域表示に座標を持たせ、共通地点表で上書きしない。
- 「アメリカ」は大陸・新国家の両方に使われるため、広い地域の代表位置とする。「アメリカ合衆国」、植民地名、都市名の具体的な記載は別々に配置する。
- 「プリマス」は本章では北米のプリマス植民地を基本とし、イギリスのプリマス港と区別する。
- サンサルバドル島は現バハマの同名島の代表位置を使用し、コロンブスの具体的な上陸浜を確定した表示とはしない。
- 家名や人物の短縮名は完全名を優先する。序数のない同名君主を新しい人物として機械的に増やさない。

航路は本文で移動の両端が同じページに記される場合に表示する。大西洋三角貿易のほか、喜望峰経由のインド航路、アカプルコ貿易などを概略線で示す。太平洋を横断する線は日付変更線で2本に分け、ユーラシアを横切る誤った線を避ける。地理図は既存の世界基図と `public/map-camera.js` の共通拡大上限をそのまま使う。地理図の個別の拡大制限解除はしない。

代表地点の確認資料として、[米国国立公園局のヨークタウン戦場案内](https://www.nps.gov/York/)と[ヴェルサイユ宮殿の歴史案内](https://en.chateauversailles.fr/discover/history)も確認した。前者はヴァージニアの戦場、後者は王権の拠点としての宮殿の配置確認に使用した。
