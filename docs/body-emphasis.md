# 本文の強調基準（v0.082）

## 第6章を確認した結果

イスラーム世界の色付き太字・本文色の太字は、見出しの文字から毎回決めているものではない。`docs/source-edition/decoration-1.json`〜`decoration-5.json` に、原画像で確認した装飾が段落・文字列・出現回数ごとに記録され、`scripts/build-source-edition.mjs` が表示用の印に変換している。

色付き太字には、主要な人物・王朝・都市・戦い・宗教・制度・文化の語が多い。本文色の太字には、関連人物や地域、用語の説明、政策の内容などが多い。例えば第1ページでは「アラブ人」「イエメン」が色付き、「遊牧民」「隊商貿易」が本文色の太字になっている。ただし、分類名だけで色を断定できる規則はなく、「メッカ」「スンナ派」「アウラングゼーブ」などは説明の文脈によって両方の扱いがある。試験上の重要度を機械的に判定する指定ではない。

明るい画面は濃い赤茶色 `#9d3825`、暗い画面は明るい赤茶色 `#ffb49f`、どちらも太さ700。本文色の太字は通常本文の色を継承し、文字サイズは変えない。この配色を他の章の追加装飾にも共用する。

## 他の章で装飾が不足していた理由

第1〜5章・第7章は、書き起こしにある太字を本文色の印として保存していた。太字のあるページは順に58/103、23/136、33/107、140/141、42/118、165/253ページで、特に第2・3・5章では重要語も通常文字のままのページが多かった。

以前の `story-emphasis.js` は `strong` 要素だけを調べていたが、原文対応版の本文は `span.source-bold` を使っていた。そのため、以前の見出しに基づく色付けも働いていなかった。さらに、太字のないページでは、対象を広げるだけでは不足を解消できない。

## v0.082で追加する装飾

第6章の確認済み装飾を保持し、第1〜5章・第7章の858ページにアプリ側の装飾を補う。原画像の色を新たに確認した記録とは混同しない。本文の文字・記号・掲載順・改ページ・元の太字・読み仮名を保持する。`sources` の原文資料には書き込まない。

1. `public/story-emphasis-terms.js` の章別の表で、制度・思想・宗教・出来事・文化などの重要語を拾う。「九品中正」「門閥貴族」「予定説」など、地理上の地点を持たない語も対象にする。
2. 既存の太字と、章に対応する名称表の人物・建物・王朝・主要な川、見出しにある地名を関連語の候補にする。地図にある名前を一律に色付きにしない。
3. 本文に実際にある語だけを選ぶ。見出しの主題語を優先し、本文の重要語で補い、色付きは1ページ最大4語とする。それでも主題が選べない場合だけ、関連語の先頭2語を使う。
4. 選んだ主題語は色付き太字、残りの候補は本文色の太字にする。追加する装飾は同じ語のページ内最初の出現に限り、後の繰り返しは元の装飾を保つ。
5. 長い正式名称を優先して語中の短い名前を重ねない。中黒・等号の表記ゆれを扱い、「キタイ」中の「タイ」や「新しい」「周り」「明るい」を国・王朝の名前として強調しない。年代だけの語を主題にしない。

これらは、主題と関連説明を区別するための表示上の規則であり、原資料の色を復元した指定や試験の出題頻度の分類ではない。元の装飾には `source-bold`・`source-red-bold`、追加した装飾には `story-bold`・`story-key-term` を使い、別々に検査できるようにする。

## 表示と検査

`history-story.js` が本文を表示する直後に共通処理を呼ぶ。初回表示、場面番号、前後ボタン、直接指定したページでも同じ結果になる。追加装飾だけを取り除いて再適用でき、元の太字や読み仮名を分割・削除しない。従来の要素監視による再判定は使わない。

- `npm run check:source:browser`：全1013ページを幅1280・390で表示し、本文・元の太字・色付き太字・読み仮名・追加した強調語を照合。全7章の代表ページは明暗両方で実際の色・太さ・文字サイズを比較し、元の太字と読み仮名をまたぐ場合や再適用も検査する。
- `npm run check` と `npm run build`：従来の原文対応、再生成の一致、目次、地図の名称、共通の拡大上限、参照先も検査する。

画面確認は開始前に自動読み上げと音声再生を無効にする。地図や地図の共通拡大上限は今回変更しない。
