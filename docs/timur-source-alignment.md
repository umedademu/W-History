# 04 ティムールの遠征・原資料対応表

更新日：2026年9月7日

## 対応範囲と章の境界

04章は `02_timur_and_safavid.md` の p.334「モンゴル帝国が衰えると、中央アジアからティムールが勢力拡大！」から、オトラルでの病死と図「ティムール朝の発展」までを扱う。

p.335「ティムールの死後、各地に封じられた一族が権力を争った！」から始まるシャー＝ルフ、ウルグ＝ベク、文化、ウズベク三ハン国、カザフ、ロシア帝国は05章の担当範囲とする。04章では、ティムール本人の死とティムール朝の滅亡を同一視しないため、「本人の死後も子孫の王朝は続く」とだけ補足する。

## 削除した補助情報

原資料を並べて読んだときに本筋が分かれるため、原資料のティムール部分にないトクタミシュ、サライ付近、イスファハーン、インドの戦象を04章の表示から外した。年代も原資料に明記されるアンカラの戦い［1402］以外は、出来事の順序を示す表現へ改めた。

## 専用検査

`scripts/timur-source-names.json` はp.334から独立して抽出した名称と話題順を記録する。`scripts/check-timur-source.mjs` は、原資料のハッシュ値、13場面の順序、各名称が本文と地図表現の双方にあること、削除対象が残っていないことを確認する。

作業ツリーに `sources` フォルダーがない場合は、原資料ファイルの絶対パスを第1引数として渡す。
