# 原書の時点と人物・制度の確認

第26回は原書の2023年9月の補足を含む当時の記述を保持する。以下の資料は図解と人物配置の確認用であり、原文を現在の説明へ書き換えるためには使わない。

- [NATOの加盟国一覧](https://nato.int/en/about-us/organization/nato-member-countries)：フィンランドとスウェーデンの加盟の時期を確認する。画面では原書の2023年9月の見通しと明記する。
- [EU理事会のシェンゲンに関する資料](https://data.consilium.europa.eu/doc/document/ST-13048-2019-ADD-1/en/pdf)：英国の参加範囲と、域内の国境管理・EUの労働者の移動を区別する。原文の文章は保持する。
- [パグウォッシュ会議による宣言の成立史](https://pugwash.org/wp-content/uploads/2014/02/2005_history_origins_of_manifesto3.pdf)：1955年のアインシュタイン死去と宣言の成立を確認する。1957年の会議の現地に本人を配置せず、宣言の精神に関する過去の人物の参照として示す。

原文の政治評価、年次、役職、領有権の表現、「現在」という語、表記も保持する。最新の情勢を解説する教材ではなく、参照専用の原文をたどる教材として入口に時点を示す。
