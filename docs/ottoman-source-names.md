# 07 資料中の名前の照合

`scripts/ottoman-source-names.json` に、p.337〜343から独立して抽出した136件を記録した。各項目は資料上の範囲、表示段落、表記、地図対象を持つ。

対象には、人物、地域、都市、国・王朝、戦い、宗教集団、軍団、建物、制度を含む。別名が学習上必要なものは、同じ地図対象へ結びつける。

- アナトリア（小アジア）
- アドリアノープル（エディルネ）
- クリミア＝ハン国（クリム＝ハン国）
- カール5世（スペイン王カルロス1世）
- シナン（スィナン）
- スレイマン＝モスク

検査は項目が章内のどこかに存在するだけでは合格にしない。指定した段落の本文と、その瞬間の地図の双方に同じ対象があることを確認する。
