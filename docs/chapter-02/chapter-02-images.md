# 古代地中海世界の人物・建物・道具の画像と演出（第2章）

v0.074（2026年9月）。内蔵の画像生成機能を使用して生成したスプライトアトラスから切り出し、透過処理を行ったドット絵画像を配備。第2章の全136ページにおいて、簡易アイコン（SVG）のフォールバックを完全撤廃し、登場人物および歴史的建造物をすべて100%ドット絵（透過PNG）化。あわせて、移動・進軍アニメーションおよび戦闘・対決・感情変化演出を実装。

## 保存先

すべて `public/images/ancient/` に保存。人物は128×192画素、建物・道具・乗り物は192×192画素の透過PNG。
背景透過処理と最近傍方式によるスケーリングを行い、ドット絵の鮮明さを保持しています。

## アニメーション演出仕様

1. **行軍・遠征ルート連動（`route`）**:
   - アレクサンドロス東征（イッソス、エジプト、ペルセポリス、インダス川）、ハンニバルのアルプス越え・カンネー進軍、スキピオのザマ遠征、カエサルのルビコン川渡河、パウロの伝道旅行などで、キャラクターが滑らかに移動し歩行アニメーションを実行。
2. **主要戦闘の対決演出（`battle`）**:
   - マラトンの戦い、テルモピレーの戦い、サラミスの海戦、プラタイアの戦い、レウクトラの戦い、カイロネイアの戦い、イッソスの戦い、ガウガメラの戦い、カンネーの戦い、ザマの戦い、アクティウムの海戦などで、戦場リングの点滅と両陣営の対峙を表現。
3. **勝敗・感情変化（`afterImage`）**:
   - 戦闘終了後に、勝利陣営は歓喜（`roman-victory`）、敗北陣営は悔恨・敗走（`greek-defeated`, `soldier-retreat`）へ切り替わり。
4. **歴史的台詞の吹き出し演出（`bubble`）**:
   - ソクラテス、ペリクレス、カエサル、ハンニバル、アウグストゥス、イエス、パウロなど、歴史的名言や思想を吹き出しで動的表示。
