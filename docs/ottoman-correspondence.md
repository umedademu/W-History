# 07 本文と地図の対応

42ページ・90段落を、段落ごとに双方向で照合する。

- 本文に出る人物・地域・王朝・出来事・集団・建物・制度は、その段落の地図にも出す。
- 地図に出す対象は、同じ段落の本文でも説明する。
- 地域は地図上の位置または範囲、人物と建物は該当地点、進軍と外交は経路で示す。
- 文字列だけの用語一覧は設けず、既存の位置・範囲・矢印・人物絵・建物絵へ結びつける。

`public/ottoman-pages.js` は、各段落の本文から名前を認識し、その段落で必要な地図対象だけを選ぶ。旧地図に残る余分な対象、説明にない経路、説明にない注記は表示対象から外す。

照合は `node scripts/check-ottoman-source.mjs` と `node scripts/check-ottoman-pages.mjs` で行う。前者は資料から独立して作った136件の一覧を、後者は全90段落の位置・経路・表示対象を確認する。
