## 原文と改ページ

`sources` 内の原文は参照専用とし、修正・補完・整形を行わない。通常本文は文章・順番・太字をそのまま保持する。独立したまとめ・比較表・年号欄・図表内の文字などは省く一方、通常本文に含まれる比較・整理の説明は残す。原文に欠けや表記の不整合がある場合は、章ごとの記録に注意点を残す。

章ごとに原文の掲載範囲と省略理由を記録し、明示的なページ構成表を保存する。文字数や原文の段落数だけで自動的に改ページしない。導入文は説明と、結びの補足は対応する本文とまとめ、原因・経過・結果を理解できる位置で区切る。複数の原文段落を同じページへまとめる場合も、段落区切りを表示する。

## 表示と地図

0.069ではトップページを章・回・節の文字だけの目次に変更した。各節の名称を教材へのリンクとし、サムネイル・短い解説・年代・ページ数・冒頭の宣伝文や収録件数は掲載しない。目次は `scripts/build-book-library.mjs` から再生成する。

`public/book-chapters.js` が章と回の構成、`public/story-volumes.js` が全教材の順序と次の教材への移動を管理する。番号は章ごとに01から振り直し、各教材末尾には同じ章の教材を並べる。章末では次の章へ進み、最終章の末尾では教材一覧へ戻る。既存の入口と転送先は維持する。

追加5章の本文・地理定義は章専用のファイルで管理する。`public/chapter-story.js` は開いた章の本文だけを読み込み、共通の表示処理を使用する。全体の生成・検査では `public/all-editions.js` を使う。既存の `source-edition.js` は第1章・第6章の互換用入口として保持する。

`public/chapter-geography.js` と `map-name-coverage.js` は、本文の章に対応した名称表で地図名を照合する。同名の王朝・人物を章の違いによって混同しない。都市は遺跡や現在地、王朝・人物はその説明に関係する拠点に置く。宗教や制度など、所在地を持たない概念を地理的な点にはしない。人物・建物の記号は肖像や復元図ではない。

全地理図で `public/map-camera.js` の共通拡大上限を適用する。最低でも東西32度・南北24度の範囲を保ち、地名が多いページでは必要な広域を表示する。海岸線は共通の世界基図を使用し、川・移動・征服・交易の経路は大まかな位置関係を示す。

## 再生成と検査

- `npm run build:source`：章別の本文を再生成し、全教材の入口・一覧・ページ数を更新する。
- `npm run check:chapters`：追加5章の原文対応・掲載順・太字・目次・地図の名前と座標・再生成の一致を検査する。
- `npm run check`：既存章も含め、原文の非改変・全教材の参照先・地図の拡大上限・目次・本文を検査する。
- `npm run build`：原文資料を置かない公開環境向けの検査を行う。
- `npm run check:chapters:browser`：追加5章の全ページを幅1280・390で確認する。`-- --chapter=2` のように章を指定できる。
- `npm run check:source:browser`：全7章の本文と装飾を画面上で照合する。
- `node scripts/check-chapter-navigation-browser.mjs`：全128教材の一覧・入口・目次・転送先・移動を確認する。

画面確認は開始前に自動読み上げと音声再生を無効にする。ページ数の集計は [教材一覧の集計](catalog/summary.json)、書籍の目次との対応は [目次の記録](catalog/book-outline.json) を参照。
