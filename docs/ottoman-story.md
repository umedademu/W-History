# オスマン帝国・地図の紙芝居

追加版：v0.002（2026年9月6日）

## 目的と入口

提供された教科書写真の「オスマン帝国」の本文・コラム・年表を、地図と短い説明でたどる独立した教材ページ。
教材一覧から `/ottoman-story.html` を開く。
専用のドット絵と人物・制度・建物の共通記号を配置し、進軍・遷都・海戦・建設・徴税・要請などの動きを本文と対応させる。他の人物の肖像を流用して別人を表さない。
無音で、自動の場面送り、学習データの取得、学習履歴や設定の読み書きを行わない。

## 本文に沿った地図の説明（v0.010）

20場面を91の短い説明に分割。本文の名前を押すと対応する説明を一度再生し、そこで止まる。「次の説明」または説明一覧から、次に見る説明を手動で選ぶ。説明一覧・前の説明・次の説明からも選べる。「動きをもう一度」は説明1に戻り、そのコマの広い地図の導入から繰り返す。本文・まとめ・補足・見どころの名前を照合し、対応表と検査については [原文と地図の対応](ottoman-coverage.md) に記載する。

各説明の動きを一度再生して待機する。ページ内の次の説明にも、20場面の次のページにも、自動では進まない。動きを抑える設定では、各説明の結果を静止表示し、説明自体も手動で進める。金角湾・城壁の図は位置関係の模式図、制度の図は関係する拠点での模式図として注記する。小さい画面ではコマ送りの操作欄を本文に重ねない。

## 表示と操作

基図は本教材専用の `ottoman-world-map.svg`。世界全体の陸地・湖を収め、北を上にした平面の世界地図から詳細地図まで、同じ座標で連続して拡大・移動する。現在の国境は表示しない。

最初の場面では、世界全体で位置を示し、地中海周辺を経由してアナトリアへ約3.2秒で近づく。章が変わる場合や、エジプト・イラン方面・ウィーン方面などへ地域が変わる場合は、地中海周辺まで表示を広げてから約2.4秒で次の舞台へ近づく。同じ地域では約0.65秒で前の表示位置から移動する。

拡大・移動の間は場所の案内を表示し、本文と地図上の人物を待機させる。位置が定まってから本文を表示し、人物や矢印の動きを開始する。地図の下には「世界 → 地中海周辺 → いまの地域」の案内と小さな世界地図を置き、実際に大きな地図に映っている範囲を赤い枠で示す。枠は拡大・移動中も追従する。

「広い地図で位置を確認」で、どの場面でも世界全体からの導入を再表示できる。「説明へ進む」で位置案内を省略でき、「動きをもう一度」では、その場面が広い地図から始まった場合は、縮小状態からの拡大も含めて再生する（v0.008）。「広い地図で位置を確認」を使った後も世界全体から再生する。広い導入がない場面では同じコマの説明を最初から再生する。場面の連打や画面の大きさの変更では前の動きを停止し、選択中の場面を表示する。

進軍は赤、相手の進軍は青灰色、移動は緑、交易・支援要請・制度上の関係は金色の点線。
前後ボタン、左右キー、三つの章、20個の番号から場面を選択できる。
端末の「動きを減らす」設定では、冒頭や地域変更時の広い地図を静止表示する。「説明へ進む」を押すと本文と人物の最終状態を静止表示し、同じ地域への場面移動も即座に切り替える。位置案内と人物の動き、いずれも音声を使わない。

この試作は07だけに適用する。他の教材の地図表示や場面内容には適用していない。

v0.009からは、全教材で共通の配置処理により地名・人物・名前・吹き出しの重なりを避ける。拡大後の表示と人物の移動中に適用する。詳細は `docs/map-layout.md` を参照。

## v0.014 原資料の名前の省略防止

写真の337頁後半〜343頁上部と書き起こしを照合し、原資料由来の名前165項目を `scripts/ottoman-source-names.json` に記録した。本文から作り直す一覧ではなく、原資料と地図を照合するための独立した検査基準とする。ヒジャーズの本文または地図だけを削った場合にも検査が失敗することを確認する。詳しくは [原文と地図の対応](ottoman-coverage.md) を参照。

## v0.015 ページ内の手動コマ送り

ページを開くと説明1だけを一度再生して待機する。説明一覧・前後ボタン・本文の名前から選んだ説明も、一度再生して待機する。自動で次の説明へ進む処理は削除した。一時停止後は「再生を再開」、完了後は「この説明をもう一度」で現在の説明のみ再生する。ページ上部の「動きをもう一度」は説明1と広い地図の導入からやり直し、説明1の終了後に待機する。動きを抑える設定では従来どおり静止表示する。

確認：全20ページの説明1、全91説明の選択後に長時間待っても次へ進まないことを無音で検査。一時停止・再開、最後の説明の再再生、広い地図からの再再生、本文からの選択、小さい画面での操作も確認した。
