# 07 オスマン帝国

42ページ、90段落で、11世紀のトルコ人戦士のアナトリア進出から18世紀後半の産業革命までをたどる。

## 説明の流れ

1. ルーム＝セルジューク朝の崩壊、ベイリクの分立、オスマン朝の建国
2. ブルサ、アドリアノープル、コソヴォ、イェニチェリとデヴシルメ
3. ニコポリス、アンカラの敗北、バルカンを足場とする復興
4. コンスタンティノープル征服とイスタンブルの整備
5. 黒海北岸への拡大、ミッレト、商人の保護
6. セリム1世による東アナトリア・エジプト・聖都への拡大
7. スレイマン1世の東方遠征、対ハプスブルク外交、陸海の征服、通商特権、内政と文化
8. レパント、財政難、第2次ウィーン包囲、カルロヴィッツ条約
9. チューリップ時代と産業革命による力関係の変化

旧版で本筋に入り込んでいた、資料にない人物名・戦役・領土変化の挿話は除いた。ページ操作と画面構成は従来どおりである。

## 関係するファイル

- `public/ottoman-pages.js`：42ページの構成、本文、本文に応じた地図対象
- `public/ottoman-storyboard.js`：地図上の人物・地域・建物・制度と動き
- `scripts/ottoman-source-names.json`：資料から独立して抽出した136件
- `scripts/check-ottoman-source.mjs`：名前、登場順、本文と地図の一致を検査
- `scripts/check-ottoman-pages.mjs`：ページ構造、位置、経路、操作部を検査
