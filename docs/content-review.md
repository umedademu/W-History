# 追加５編の構成と原文との対応

v0.029（2026年9月7日）。01〜03・08〜09を04〜07と同じ画面・操作へ統一しました。提供資料を基に、出来事の理由・展開・結果を分けて再構成しています。

## 共通の表示と確認

- 04の基本の見た目と07の地図描画を土台に、追加５編を共通の表示処理へ移しました。各編の本文・地名・経路はそれぞれの場面ファイルで編集します。
- 地図の見出し、注目点、凡例、移動前後の説明、人物・建物の名前、吹き出し、章・場面番号、進捗表示を設けました。人物と建物は元画像の縦横比を保ちます。
- 地名や人物の大きさを測り、名前・吹き出しが互いに重ならず画面に収まる配置を選びます。地図は場面に必要な範囲に拡大します。
- 追加５編の全125場面で、画像の読込、地名の参照、章・場面・前後・左右キー・再表示、画面のはみ出し、人物同士の重なりを自動検査しています。01・02は代表的な場面を広い画面と390幅でも確認しました。
- 試験環境では開始前から読み上げと音声再生を無効にしました。アプリには音声機能や自動の場面送りはありません。
- 通常の動きでも各編の移動開始・完了・再表示・途中での場面切替・動きを減らす設定への切替を確認しました。既存４編の前進、一覧と更新情報、320幅・768幅での三カリフの場面も確認しています。
- 地名・座標・経路・登場物・章の参照先を公開前の検査に加えました。従来の確認では見逃していた、文化編の未定義のマラケシュも補っています。

## 書き起こし資料からの補正と補足資料

原文の学習項目を土台としつつ、書き起こしに含まれる誤記や、誤解を生む断定をそのまま採用しない方針です。元の資料ファイルは変更せず、公開する説明を補正しています。

| 項目 | 公開する説明の整理 |
| --- | --- |
| コーランの翻訳 | 「翻訳は一切禁止」とせず、アラビア語原文の重視と翻訳の存在を区別。ペルシア語の行間訳が付いた実物資料を参照。[メトロポリタン美術館の写本](https://www.metmuseum.org/art/collection/search/454114) |

| マムルーク朝 | アイン・ジャールートではクトゥズと将軍バイバルスらが戦い、その後バイバルスがスルタンとなる順序を整理。1291年のアッコン攻略は別の君主の時代。[ライス大学の世界史教材](https://openstax.org/books/world-history-volume-1/pages/17-2-from-the-mamluks-to-ming-china) |

| 数学と光学 | ゼロの発明を特定の学者へ帰属させず、インド由来の知識の受容・体系化として説明。光学と天文観測を別場面に分ける。[セントアンドルーズ大学の数学史](https://mathshistory.st-andrews.ac.uk/HistTopics/Arabic_mathematics/)、[光学史](https://mathshistory.st-andrews.ac.uk/HistTopics/Light_1/) |
| 美術 | 偶像崇拝の回避を、人物画が一切存在しないという説明にしない。宗教建築と写本・工芸で用途が異なることを補足。[メトロポリタン美術館の人物表現の解説](https://www.metmuseum.org/exhibitions/listings/1999/islamic-ornament-part-iv) |
| アフリカの地図 | マリンディを東経40.12度・南緯3.22度に訂正。モンバサ・キルワ・大ジンバブエ・ソファラなども実際の地域に配置し、基図を南緯26度まで拡張。[ユネスコのキルワ解説](https://whc.unesco.org/en/list/144/) |

書き起こしにある「マンスラブダール」は「マンサブダール」に整理しました。人物の内心を断定した文章、真偽が不確かな発言の引用、過度な「世界初」「完全」といった表現は、学習上の要点に置き換えています。吹き出しは説明のための創作です。
