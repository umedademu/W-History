# 地図上の文字と人物の配置

更新版：v0.009（2026年9月6日）

## 対象と表示

全9教材に共通の配置処理 `public/map-layout.js` を適用する。地名同士だけでなく、人物・建物・名前・吹き出し、方角、上下の補足説明、サファヴィー編の広場の模式図を考慮する。

地名の表示に必要な幅と高さを測って配置した後、人物ごとに画像・名前・登場後の吹き出しを含む領域を確保する。地名や人物をずらす場合は元の場所と細い線で結ぶ。都市の印と地形、移動経路の座標は変更しない。

人物の移動中も位置を計算し直す。前の配置も考慮し、できるだけ元の場所の近くに表示する。吹き出しが出る前から必要な空きを確保し、画面端や下部の説明欄を避ける。置ける場所がない場合は、重なる候補で妥協せず、地図の高さを増やして再配置する。

07の世界地図からの拡大・小地図・再生は維持する。拡大中は従来どおり本文と人物を待機させ、舞台に近づいてから人物を配置して動きを開始する。

## 構成

- `public/map-layout.js`：表示範囲の計測、空き領域の探索、地名の配置、移動中の人物の配置、引き出し線。
- `public/history-story.js`：01〜03・08〜09で共通処理を利用。
- `public/timur-characters.js` と `public/timur-story.js`：04の人物・地名に適用。
- `public/timur-after-story.js`：05で利用。補足説明と方角表示の間隔は専用の装飾ファイルで確保。
- `public/safavid-story.js`：06で利用。広場の模式図の領域も避ける。
- `public/ottoman-story.js`：07で利用。
- `scripts/check-map-layout.mjs`：同じ地点に人物が集まる場合、画面端、空きがない場合の判定を検査。通常の構築時にも実施する。

## 表示確認

ブラウザーの試験では開始前に読み上げと音声再生を無効にする。全9教材の各場面を、パソコン幅とスマートフォン幅で確認する。地図上の文字、人物・名前・吹き出しの表示領域を比較し、重なりと画面端からのはみ出しを調べる。静止状態に加えて、移動開始・移動途中・到着後も確認する。

添付例のオスマン編冒頭は画像でも確認し、地名と君主・騎兵・名前・吹き出しが分かれて読めることを確認する。07の地図の拡大と「動きをもう一度」も合わせて確認する。

今回の確認では、全9教材を幅1440・800・390・320で検査した。幅1440・390では動きの途中も含む計2624回の表示領域の比較を行い、文字・人物の重なり、画面端からのはみ出し、画面の実行エラーはいずれも0件だった。音声の再生試行も0件。07の世界・地域からの拡大再生、途中の省略、連打、画面幅変更、動きを減らす設定も確認した。
