## 編集と確認

`npm run check` は構文、ローカル参照先、教材の入口、Ankiへの依存、公開設定を検査します。追加５編は地名・座標・経路・人物・章の入口・操作部品を全場面で検査します。01は27場面・原資料由来197項目、02は27場面・249項目、03は49場面・608項目について、同じ場面の本文と地図への双方向掲載、話題の順序、地図に出す地点名・地域名・人物名・建物名の本文掲載、対象範囲外の先取り語を検査します。07は地図の向き・表示範囲・位置案内・移動の切り替えに加え、42ページ・90段落で本文と地図の名前の双方向一致、原資料の名前136項目、42ページの説明順と重要な経緯、地図の位置・経路・効果・画像の対応も検査します。08・09は原資料に沿う場面順と、流れを支える重要語の保持を検査します。実際の表示は `npm run dev` で確認します。`npm run build` は原文ファイル自体の照合を除く検査を実施し、生成処理なしで `public` を公開します。

原文はGitの管理対象外のため、公開用検査では原文ファイルを読み込まない。npm run checkは手元で原文の改変有無・抽出範囲も照合する。npm run buildは--publishedを指定し、管理対象の対応表による本文・地図・順序・構文・参照先の検査を実施する。原文の追加送信や編集は行わない。

## 02の縦配置の試作（v0.035）
02のみ、地図を全幅、説明欄をその下に配置。説明欄は見出しと本文に限定し、場面番号・年代・小見出し・末尾の補足を非表示にする。ページ送りは画面下端に固定し、その分の下余白を確保。地図タップによる再生は維持。他章の配置は変更しない。

## 全章への縦配置の適用（v0.036）
02の試作を全章へ適用。全幅地図の下に見出しと本文を置き、番号・年代・小見出し・末尾の補足を非表示にする。ページ送りを画面下部に固定し、移動時は地図先頭へ戻る。本文の重要語は下線・帯状背景を取り除いて太字で示す。共通の配置はstory-layout.cssに集約。

## 本文の読みやすさ（v0.037）
全章の説明欄はメイリオを優先するゴシック体、通常17px・狭い画面16px、行間1.9倍とする。本文は最大45文字相当の幅で中央に配置し、見出しの左端も揃える。暗いテーマは柔らかい白（#e4ebe7）とし、重要語も同色の太字で示す。地図の寸法は維持。

## 主題語の強調（v0.038）
本文の既存の太字から見出しにも登場する語を優先し、最大4語を色付きの太字にする。該当語がない見出しでは年代だけの語を除いた先頭2語を使用。別名・在位表記は判定時に除き、同じ語の各出現箇所を揃える。これは主題語を選ぶ表示上の規則であり、試験上の重要度を保証する分類ではない。暗いテーマは落ち着いた黄色、明るいテーマは濃い黄褐色。他の固有名詞は本文色の太字を保つ。下線なし、本文サイズと行幅は維持。

この旧方式は、原文対応版で太字の要素形式が変わったため働いていなかった。v0.082では以下の方式へ置き換える。

## 全章の本文装飾（v0.082）

第6章の画像照合済み装飾では、主な人物・王朝・出来事・制度・文化などに色付き太字、関連人物や補助説明に本文色の太字が使われる傾向がある。同じ語も文脈によって扱いが変わる。その記録を保ち、第1〜5章・第7章の858ページへ同様の二段階の強調を補う。

見出しの主題語、章別の制度・思想・文化などの重要語、元の太字、章に対応する人物・建物・王朝などの名前から、本文に実際にある語を選ぶ。色付きは1ページ最大4語、他の関連語は本文色の太字とし、追加装飾は同じ語のページ最初の出現に限る。長い正式名称と文脈を優先し、単語の一部や年代だけの誤選択を避ける。明るい画面は第6章と同じ濃い赤茶色、暗い画面は明るい赤茶色、太さ700、本文と同じ文字サイズ。本文の行幅・段落・地図の拡大上限は維持する。

追加装飾は原画像の装飾記録と別の印で管理し、原文の文字・記号・順序・元の太字・読み仮名を保持する。原資料の色を新たに確認したものや試験上の重要度を保証する分類として扱わない。詳細と検査は[本文の強調基準](body-emphasis.md)を参照。

## 地図文字の可読性（v0.039）
通常の地図ラベルは16px（狭い画面14px）、人物・建物の名札と吹き出しは14px（狭い画面13px）。メイリオを優先し、地図ラベルの縁取りは2pxとする。暗いテーマは明るい文字と暗い縁取りに統一。名札の幅も拡張し、既存の実寸測定による配置処理へ反映する。都市構造図・世界からの導入図は固有の配置を維持する。

## 地図の背景付きラベル（v0.040）
通常の地名は18px（狭い画面16px）の縁取りなし文字と無地の背景板に変更。背景板の余白を含めて重なり回避する。人物名・吹き出しも無地の背景と高い明暗差で統一。小さな都市構造図と世界の導入は対象外。

## 地図文字の簡素化（v0.041）
地名の背景板を撤去。人物名・吹き出し・動作説明の背景と枠も除去。地名15px、人物名と吹き出し14px（狭い画面はそれぞれ14px・13px）に縮小。配置の余白も文字のみの寸法に合わせ、本文サイズは維持。

## 地図の描画品質（v0.043）
人物・建物の透明な余白を表示寸法から除き、描かれた部分を既存の表示枠へ縦横比を保って収める。画像は書き換えず、読み込み時に不透明部分の範囲を一度計測する。縮小時は通常の滑らかな描画を使い、低解像度画像は引き伸ばさない。画像が切り替わった場合も再計測する。
地名は画面上13px、海域名12px、人物名・吹き出し・動作説明12px。地図の拡大率に文字サイズが左右されないようにし、文字の縁取りを1.5pxに薄くする。地名の背景板は追加しない。
