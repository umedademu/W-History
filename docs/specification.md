# W-History の構成

現在の版は v0.050（2026年9月10日）。中東史全14編、合計155ページ、人物・建物の画像を収録しています。参考書全33枚の情報を完全に書き起こした資料集（sourcesフォルダ・全5編＋対照表）を整理し、保管しています（公開管理からは除外）。

## 公開ファイル

- `public/index.html`：全14教材を選ぶ一覧（通史順に再編）。
- `public/library.css`：一覧・更新情報・見つからないページの見た目。
- `public/theme.js` と `theme.css`：全ページ共通のライト・ダーク切り替え、選択の保存、暗色時の本文・地図・操作部品の配色。
- `public/changelog.html`：利用者向け更新情報。
- `public/404.html`：存在しないページの案内。
- `public/source-edition.js`：全14教材・155ページの実際に表示する原文本文、装飾、地図の対応。
- `public/source-decoration.css`：原画像の赤太字・黒太字・読み仮名の表現。
- 各 `*-story.html` と `*-story.js`：教材の入口と既存の地図・人物の描画。旧 `*-scenes.js` の地理定義は維持するが、公開本文は `source-edition.js` を使用する。
- `public/islamic-world-map.svg`：アフリカ・地中海・アジアの広域基図。南部アフリカとベンガルも表示範囲に含みます（経度−18〜122度、緯度−26〜55度）。
- `public/timur-map.svg`：中央アジア・中東・インドを収める広域基図。
- `public/ottoman-world-map.svg` と `ottoman-orientation.js`：10〜12専用の世界地図と、世界から地域へ近づく導入・小地図による位置案内。
- `public/images/`：各教材専用の透過ドット絵PNG画像。

01〜06・13〜14は `history-story.js` と `history-story.css` で地図・人物・操作を共通化し、07の `timur-story.css` を画面の土台に使います。公開本文は原文対応データから生成し、各教材で地図処理を呼び出します。

全14教材は `map-layout.js` で地名・人物・名前・吹き出しの大きさを測り、重なりや画面端へのはみ出しを避けます。人物の移動中も再配置し、表示をずらす場合は地理上の位置と細い線で結びます。詳しくは `docs/map-layout.md` に記載しています。

全公開ページはヘッダーの「ダーク」「ライト」で表示を切り替える。初回は端末の明暗設定に合わせ、利用者が切り替えた後は同じ端末の次回表示にも反映する。暗色時は本文だけでなく、地図の基図・地名・人物名・吹き出し・進軍線・現在位置の強調も読み取れる配色にする。詳しくは `docs/theme.md` に記載しています。

全14教材の場面見出しは、本文より2画素大きい太字で表示します（通常16画素、画面幅1000画素以下では15画素）。固定の改行を使わず、表示幅に合わせて折り返し、見出し下の余白を10画素に統一します。07の地図導入の見出しも同じ指定に揃え、共通の `timur-story.css` で管理します。

各教材は独立したHTMLのまま維持し、教材一覧と相互リンクから開きます。地図のSVGは維持し、人物・建物・道具にはPNG画像を使います。07では専用画像のない対象を役割に応じた共通の記号で補います。前後ボタン・左右キー・場面番号・動きの再表示に対応し、07は42個の番号だけで全ページを直接選べます。

07では、冒頭や地域変更時に広い地図で位置を示し、拡大が終わってから本文と人物の動きを開始します。小さな世界地図に現在の表示範囲を示し、いつでも世界から位置を確認し直せます。端末の「動きを減らす」設定では、広い地図を静止表示してからボタンで説明へ進みます。各場面は3〜4の説明に分かれ、名前からの移動・一時停止・続けて再生に対応します。詳しくは `docs/ottoman-story.md` と `docs/ottoman-coverage.md` に記載しています。

## 編集と確認

`npm run check` は構文、ローカル参照先、教材の入口、Ankiへの依存、公開設定を検査します。追加５編は地名・座標・経路・人物・章の入口・操作部品を全場面で検査します。01は27場面・原資料由来197項目、02は27場面・249項目、03は49場面・608項目について、同じ場面の本文と地図への双方向掲載、話題の順序、地図に出す地点名・地域名・人物名・建物名の本文掲載、対象範囲外の先取り語を検査します。07は地図の向き・表示範囲・位置案内・移動の切り替えに加え、42ページ・90段落で本文と地図の名前の双方向一致、原資料の名前136項目、42ページの説明順と重要な経緯、地図の位置・経路・効果・画像の対応も検査します。08・09は原資料に沿う場面順と、流れを支える重要語の保持を検査します。実際の表示は `npm run dev` で確認します。`npm run build` は原文ファイル自体の照合を除く検査を実施し、生成処理なしで `public` を公開します。

## データと将来の連携

現時点では固定教材の閲覧のみで、利用者の記録を保存しません。追加のサービスへの接続や秘密情報は不要です。Anki側のコードを共有せず、相互リンクやスコア連携を追加する際は接続方法を別途決めます。

## v0.032の表示整理
全章で小カテゴリ、地図上部の見出しと注目点、凡例、地図の補足一覧・位置の説明、要点欄を非表示にした。既存描画処理が参照する要素は非表示で保持する。再生ボタンは地図全面を覆う透明なボタンへ移動し、クリック・タップ・Enter・Spaceで従来と同じ再生処理を呼ぶ。07の縮小状態からの拡大も引き継ぐ。狭い画面でページを送った際は地図と本文の先頭へ移動する。

## v0.033のヘッダー整理
全章の上部にあるシリーズ名・章タイトル・紹介文を削除し、章の目次を先頭に配置した。教材一覧へのリンク、バージョン、明暗切替はページ下部へ移した。ブラウザーのタブ名とページの説明情報は維持する。

## 公開時の検査（v0.034）
原文はGitの管理対象外のため、公開用検査では原文ファイルを読み込まない。npm run checkは手元で原文の改変有無・抽出範囲も照合する。npm run buildは--publishedを指定し、管理対象の対応表による本文・地図・順序・構文・参照先の検査を実施する。原文の追加送信や編集は行わない。

## 02の縦配置の試作（v0.035）
02のみ、地図を全幅、説明欄をその下に配置。説明欄は見出しと本文に限定し、場面番号・年代・小見出し・末尾の補足を非表示にする。ページ送りは画面下端に固定し、その分の下余白を確保。地図タップによる再生は維持。他章の配置は変更しない。

## 全章への縦配置の適用（v0.036）
02の試作を全章へ適用。全幅地図の下に見出しと本文を置き、番号・年代・小見出し・末尾の補足を非表示にする。ページ送りを画面下部に固定し、移動時は地図先頭へ戻る。本文の重要語は下線・帯状背景を取り除いて太字で示す。共通の配置はstory-layout.cssに集約。

## 本文の読みやすさ（v0.037）
全章の説明欄はメイリオを優先するゴシック体、通常17px・狭い画面16px、行間1.9倍とする。本文は最大45文字相当の幅で中央に配置し、見出しの左端も揃える。暗いテーマは柔らかい白（#e4ebe7）とし、重要語も同色の太字で示す。地図の寸法は維持。

## 主題語の強調（v0.038）
本文の既存の太字から見出しにも登場する語を優先し、最大4語を色付きの太字にする。該当語がない見出しでは年代だけの語を除いた先頭2語を使用。別名・在位表記は判定時に除き、同じ語の各出現箇所を揃える。これは主題語を選ぶ表示上の規則であり、試験上の重要度を保証する分類ではない。暗いテーマは落ち着いた黄色、明るいテーマは濃い黄褐色。他の固有名詞は本文色の太字を保つ。下線なし、本文サイズと行幅は維持。

## 地図文字の可読性（v0.039）
通常の地図ラベルは16px（狭い画面14px）、人物・建物の名札と吹き出しは14px（狭い画面13px）。メイリオを優先し、地図ラベルの縁取りは2pxとする。暗いテーマは明るい文字と暗い縁取りに統一。名札の幅も拡張し、既存の実寸測定による配置処理へ反映する。都市構造図・世界からの導入図は固有の配置を維持する。

## 地図の背景付きラベル（v0.040）
通常の地名は18px（狭い画面16px）の縁取りなし文字と無地の背景板に変更。背景板の余白を含めて重なり回避する。人物名・吹き出しも無地の背景と高い明暗差で統一。小さな都市構造図と世界の導入は対象外。

## 地図文字の簡素化（v0.041）
地名の背景板を撤去。人物名・吹き出し・動作説明の背景と枠も除去。地名15px、人物名と吹き出し14px（狭い画面はそれぞれ14px・13px）に縮小。配置の余白も文字のみの寸法に合わせ、本文サイズは維持。

## 地図の表示を再調整前へ復元（v0.042）
地図の文字・人物名・吹き出しの書式と配置の余白をv0.038時点（ee01be2）へ復元。v0.039〜0.041の地図向け上書きを撤去した。全幅地図・下段本文・固定ページ送り・本文の文字調整と主題語の色分けは維持。

## 地図の描画品質（v0.043）
人物・建物の透明な余白を表示寸法から除き、描かれた部分を既存の表示枠へ縦横比を保って収める。画像は書き換えず、読み込み時に不透明部分の範囲を一度計測する。縮小時は通常の滑らかな描画を使い、低解像度画像は引き伸ばさない。画像が切り替わった場合も再計測する。
地名は画面上13px、海域名12px、人物名・吹き出し・動作説明12px。地図の拡大率に文字サイズが左右されないようにし、文字の縁取りを1.5pxに薄くする。地名の背景板は追加しない。
第07章は、画像が設定された軍人・騎兵なども人物用の縦長枠で扱う。第02章の一人・複数人物・携帯幅（390px）・明暗テーマ、第04章の画像切替、第05〜07章の表示、第07章の拡大からの再生を画面で確認。透明部分・縦横比・足元・小さい元画像の扱いは自動検査にも含める。

## 方向キーでのページ送り（v0.044）
全9章で左右キーによるページ送りは、地図上端への自動スクロールを行わない。画面上の前後ボタン・ページ番号を押した場合は、従来どおり地図上端へ移動する。

## 地理図の拡大上限（v0.045）
全章の地理図は、画面内に最低でも経度32度・緯度24度の範囲を確保する。倍率の数値は基図の座標単位によって異なるため、public/map-camera.js の maximumMapScale に画面寸法と投影関数を渡して共通上限を求める。既存の人物・移動経路を収める計算と、この上限の小さい方を使う。広域の遠征図を狭めず、オスマン編の導入・地域移動にも同じ制限を適用する。人物・地名は地形と一緒に縮小しない。都市内部や広場の模式図は地理図の倍率とは別に扱う。
全155ページとオスマン編内部27シーンの範囲指定を点検。3種類の基図の座標と縦長・横長画面で、最低表示範囲と既存の広域範囲を保てることを検査する。今後の章でも拡大上限を個別に外さず、必要な詳細は位置関係が分かる地理図に模式図を併用する。

## 全教材の原文本文と装飾（v0.050）

全14教材の104段落を155ページに分けて掲載する。本文は字句と順序を保ち、囲み・図表・地図ラベル・年号・欄外補足から独立した説明を追加しない。既存の地図・人物・共通拡大上限を維持し、本文にない表示名称を除く。

原画像30枚の本文をGemini 3.8 Flashで確認し、赤太字と黒太字を出現箇所単位で保存した。赤太字は強調色の太字、黒太字は本文色の太字とし、暗い画面でも区別する。原画像にある読み仮名も表示する。見出しとの部分一致で本文の装飾を追加しない。

画像に基づく書き起こしの補正はアプリ側の対応記録に残し、sources内の原文資料は変更しない。詳細・再生成・検査は [原文の再現方針](source-edition/README.md) を参照。旧版の章別用語網羅検査は当時の確認記録であり、現行本文の合格条件には使わない。
