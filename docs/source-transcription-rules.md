# 原画像からの書き起こしと強調の表記

2026年10月2日、v0.088。利用者が指定した全文書き起こしの条件に、原画像の強調を保存する方法を加える。初回の適用対象は「近代・現代」第1章第1回の15〜40ページ。

## 本文とページ

1. 語り口調の本文を一言一句書き起こす。図・地図内の文字、凡例、イラストの吹き出し、図版の題名・説明、比較欄、コラム、年号欄も含める。要約や本文の箇条書きへの圧縮は行わない。
2. 指定範囲の全ページを、原文の順番で保存する。章扉も含め、各ページの冒頭は数字だけの `## 15` の形式にする。
3. ページをまたぐ文章・語句は元の区切りを残す。途中で切れた語句に接続語や句読点を補わず、次ページから原文の続きを記載する。
4. 見出しには見出し記号、図表の文字には表、囲み・吹き出しには引用を使用する。語り口調の本文は段落のまま保存する。
5. ページ上部の回・節の表示と、繰り返し印刷される欄外の章目次も各ページに収録する。印刷されたページ番号は冒頭の見出しで表す。
6. 書籍名・著者名・解説・訂正・出典注を原文本文に追加しない。読み取りの記録と補足は `docs` に保存する。

## 強調の区別

実際に印刷されている文字の範囲にだけ指定する。重要そうな語句を追加で選ばず、同じ語句が再登場しても、その場所の原画像に従う。

| 原画像の表現 | 書き起こしの形式 |
| --- | --- |
| 黒い太字 | `**語句**` |
| 赤・緑・灰・茶の文字 | `<span data-source-color="red" style="color:#e52715">語句</span>` のように色を記録 |
| 色付きの太字 | 上の色の指定の内側に `**語句**` を入れる |
| 白抜きの見出し・番号 | `data-source-color="white"` と `data-source-background="red"` などで文字色と背景を分け、太字なら内側に `**語句**` を入れる |
| 下線 | `<u data-source-underline-color="red" style="text-decoration-color:#e52715">語句</u>`。黒・灰の下線も色を分ける |
| 赤い枠に入った図中文字 | `<span data-source-border="red" style="border:1px solid #e52715;padding:0 0.2em">語句</span>` |
| 地図の色面・境界線の凡例 | 色付きの `■`・`━` に `data-source-marker` を付け、その後ろに原文の凡例を書く。凡例の文字自体を背景色付きの強調にはしない |
| 印刷された読み仮名 | `<ruby>炭焼<rt>すみやき</rt></ruby>党` のように、実際に読みが付いた文字の範囲を残す |
| 年号の覚え方の上に印刷された数字 | 読み仮名と同じ形式で、対応する語句の上に数字を保存する。例：`<ruby>ひと<rt>1</rt></ruby>` |

文字色の値は、赤 `#e52715`、緑 `#315837`、灰 `#777777`、茶 `#a43725`。白抜き見出しの桃色背景は `#f0a0a0`。色の値は紙面を読みやすく表すための近似値で、元画像から測定した値ではない。色の種類、太字、下線、背景、枠の区別は属性にも残す。

見出しを大きく表示することと、元の太字を表すことは別に扱う。太字・色・下線が重なる場合は重ねて記録し、黒い括弧で囲まれた赤い語句などは括弧と語句を別々に指定する。印刷されていない読み仮名や、字に付いていない数字は追加しない。

色や下線の表示は閲覧するソフトの対応に依存する。表示されない場合でも、文章と強調の属性をファイルから確認できる。

## 図表と文字以外の表現

表へ置き換えた図・地図は、地名、年号、図中文字、凡例をすべて収録する。表の空欄は紙面にない文章で埋めない。図の接続関係の補足が必要な場合は原文資料に加えず、説明資料へ記録する。

挿絵や顔の絵そのものには文字を創作して付けない。吹き出しの文章と、絵の題名・説明は全文収録する。原画像の文字以外の装飾と紙面の配置を画像として再制作する作業は、この書き起こしには含めていない。

## 保存と確認

作業用の草稿で原画像と照合し、ページの連続、図表・囲み・コラム・年号欄・欄外目次の収録、強調の範囲、読み仮名を確認してから `sources` へ新規保存する。保存済みの原文ファイルは参照専用とし、後から加筆・修正・整形しない。

「近代・現代」の目次はAntigravity CLI経由のGemini 3.8 Flashで読み取った。第1回は、利用者の「別にGeminiにやらせなくて自分でやってもいいよ」という許可に従い、担当が原画像を直接読んで作成した。元画像は変更せず、拡大確認用の一時画像だけを作業用フォルダへ置いた。

出典と確認範囲は[近代・現代の資料記録](modern-contemporary-sources.md)、元画像・書き起こしの内容識別値とページ別の確認記録は `docs/modern-contemporary-first-lesson.json` を参照する。

第2回（41〜54ページ）では、担当とGeminiの独立した本文の読み取りを比べ、相違を部分拡大で確認した。太字・色・下線・読み仮名の確認は本文と分けておこなった。試した方法と採用した手順は[比較記録](source-transcription-comparison.md)、ページ別の記録は `docs/modern-contemporary-second-lesson.json` に保存する。

第3回（55〜71ページ）も同じ確認手順で作成した。地図の縦線模様の凡例は、色に加えて `data-source-marker="hatch"` で区別する。漢字の上に数字、下に読み仮名がある場合は、上下の指定を付けた読み仮名を重ね、それぞれの文字色も保持する。71ページの「鍬」では、上の9と下の「クワ」を両方記録した。

指示矢印に隠れた文字を他の紙面で照合した場合は、直接読めた文字と区別して説明資料へ記録する。第3回の71ページの年号末尾は、同じ欄の語呂の数字と69ページの年号を照合して復元した。確認箇所と復元の根拠は `docs/modern-contemporary-third-lesson.json` に保存する。

第4回（72〜92ページ）も同じ確認手順で作成した。境界線の凡例は実線を `data-source-marker="line"`、点線を `data-source-marker="dashed-line"`、色面を `data-source-marker="area"` で区別する。図を表へ置き換える際にも、原画像で一度だけ印刷された文字を重複させない。

92ページの「奴」は上の数字8と下の読み仮名「ヤツ」を重ね、下の「ヤ」が赤、「ツ」が黒である境界を保存した。「火花を」の数字は、火に1、花に87、をに0を付ける。本文の読み仮名も印刷された範囲に限り、「大砲」の読みは2文字全体へ付ける。確認箇所は `docs/modern-contemporary-fourth-lesson.json` に保存する。

第5回（93〜107ページ）も同じ確認手順で作成した。地図の凡例では矢印を `data-source-marker="arrow"`、点線の矢印を `data-source-marker="dashed-arrow"`、国境の囲みを `data-source-marker="boundary"` とし、色面・縦線模様と区別する。まとめ欄の灰色の枠は `data-source-border="gray"` で記録する。

小さい「ぁ」「ぇ」、小文字の「vs.」、語句の末尾、句読点も原画像に従う。読み仮名「ちゅうかいにん」は「仲介人」全体へ付ける。107ページの「いや無理言うな」「いやなんなんだ」は赤い文字と黒い文字を分けて、印刷された数字だけを対応させた。顔の挿絵は文字へ置き換えず、挿絵の前後にある句読点は残す。詳細は `docs/modern-contemporary-fifth-lesson.json` に保存する。
