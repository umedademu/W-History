## 見た目と本文の扱い

- 章題、ページ番号、「第○回」、番号付きの節、細かな見出しの段階を整理した。ページをまたぐ文章は紙面の区切りを保持する。
- 太字・図表・引用・語呂合わせ・読み仮名は採用元の記載を基本に残した。全語句への太字の追加など、原文にない装飾の推定は行っていない。
- 書き起こし担当者の「完了したページ数」「次回開始するページ数」という作業メモは、統合本文から除いた。元資料にはそのまま残している。
- 旧版だけにある具体的な情報30件は、本文末尾の「照合保留」に出典ページとともに保存した。本文の確定的な欠落か、旧版による追加説明かを判定できないため、本文と混ぜていない。

## 確認の範囲と残っている相違

これは書き起こし相互の比較と統合であり、書籍原文との全面照合ではない。利用者の補足に従い、画像は原文の書きぶり・見出し・図と本文の配置を知るための参考にだけ使用した。別のAIへの画像読取依頼はしていない。

語呂合わせ、固有名詞の綴り、細かな言い回しなどが一致しない場合は、原則として新しい版を採用し、知識や推測で書籍の文章を作らなかった。旧版の69ページに判読不能として記録された箇所も、最新版の記載を採用したもので、原画像による正確性の確認はしていない。第1章16ページは比較できる他の書き起こしがないため、不自然に見える文言も推測修正せず残している。

第3章の重複末尾には、ソグド人の別称、阿倍仲麻呂の官職、阿羅本、玄奘の帰路、年号の覚え方などの相違がある。統合版末尾の対照表と、変更していない元資料を確認できる。

## 保存と検査

- 元資料24本と共通の目次について、移動前の内容を識別する値を記録した。移動後の24本の全内容と目次が、作業開始時と完全に一致することを確認する。
- 各章直下は `transcription.md` 1本。目次は `sources` 直下に残す。原資料・統合版・画像は従来どおり公開管理の対象外。公開するのは保管方針、出典・照合記録、参照先の変更と検査処理である。
- [source-consolidation.json](source-consolidation.json) に元資料の保管前後の場所・内容を識別する値・統合版のページ別出典・補完箇所を記録した。
- `npm run check:transcriptions -- --require-legacy` で、全元資料の存在と内容一致、統合版のページ順・第何回の見出し・埋め込み画像・照合記録との一致を検査できる。
- `npm run check` でも統合版と、残っている旧版を検査する。利用者が後日旧版を削除した場合は、旧版の直接照合を省いた本数を明示する。資料そのものがない公開環境では、非公開資料の直接検査を省略する。
- 既存アプリの原文照合は、第6章の旧5資料を `legacy` から参照する。元の行番号と本文を維持しており、今回の統合版へアプリ本文を差し替えてはいない。
