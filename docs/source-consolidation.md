## 分割と確認

- 目次に記された各回の開始ページで分割した。本文中のペルシア戦争・ポエニ戦争などの「第1回」「第2回」は講義回ではないため、分割位置には使っていない。
- 章扉の15・63・129・181・253・315・349ページは、それぞれの章の最初の回に収録した。15ページは目次に基づく章名・番号のみで、原書からの書き起こしではない。
- 15〜480ページの区切り466個すべてについて、ページ内の全文を識別する値が分割前と一致することを確認した。うち16〜480ページは465個。本文、図表、ページ番号、第何回の小見出しを保持した。
- 264ページの埋め込み画像は第16回に収録し、分割前と同一であることを確認した。
- 各ファイルの先頭にはその回の題名を置き、以前削除した編集注・照合保留・出典案内は加えていない。
- [照合記録](source-consolidation.json)に各回のファイル名・題名・ページ範囲・内容識別値を記録した。章別のページ本文の識別値は分割前から変更していない。
- 統合版の作成は既存の書き起こし相互の比較に基づく。原書との全面照合は行っていない。

## 保存と検査

書き起こし30本、共通の目次、写真は従来どおり公開管理の対象外。npm run check:transcriptions で、30ファイルの番号・書籍の題名、目次に基づく開始ページ、本文・見出し・画像の保持を検査する。npm run check と npm run build でも同じ確認を行う。

既存アプリの本文は変更していない。本文・画像の照合記録に基づく検査を継続する。

## 以前の整理
