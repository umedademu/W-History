# 公開と手元での確認

## Vercel

1. このフォルダ全体を単独のGitHubリポジトリへ登録する。
2. Vercelで新規プロジェクトを作り、そのリポジトリを取り込む。
3. プロジェクトのルートはリポジトリ直下、種類は Other。`vercel.json` の構築コマンド `npm run build`、公開フォルダ `public` を使用する。
4. 環境変数を追加せずに公開する。
5. 教材一覧、3教材、更新情報の表示と、存在しないURLが404になることを確認する。

アプリ全体を一つのページへ転送する設定は使用しません。3教材はそれぞれのHTMLとして直接開けます。ソース・資料・確認用スクリプトは `public` の外に置きます。

## 手元

`npm run dev` で `http://127.0.0.1:8766/` に起動します。公開サービスは起動せず、手元の端末だけから閲覧できます。別のポートが必要な場合は環境変数 `PORT` で指定します。

検査は `npm run build`。ブラウザーで確認するときは音声を使わず、一覧から各教材への移動、前後・章・場面番号・再表示、狭い画面、画像が欠けていないことを確認します。

## 公開後の変更

教材を編集し、版番号と更新情報を更新し、検査後に変更を保存してGitHubへ送ります。Vercelとリポジトリの連携後は、公開用のブランチへの変更が自動的に反映されます。
