# 08「ムガル帝国」原文対応表

## 対応範囲

参照資料は `sources/04_mughal_empire.md` の p.343〜346上部である。章の範囲は、バーブルの建国前史からアクバルの統治、シャー＝ジャハーン期の繁栄、アウラングゼーブ期の最大領土と分裂、インド＝イスラーム文化、インド産綿布の交易までとした。

資料は参照専用とし、内容には手を加えていない。教材では逐語的な複写を避けつつ、見出しと段落の順序、因果関係、固有名詞を保った。

## 原文外の独立場面の整理

従来の「東インド会社の政治進出」と「1858年の王朝廃止」は、この参照範囲より後の出来事であるため、独立場面から外した。ヨーロッパ進出については、原文どおりインド産綿布の利益を求める動きまでで止めた。これにより全22場面から全20場面となった。

## 08と09の境界

08は p.346上部のインド＝イスラーム文化とインド産綿布までを含める。これらは「ムガル帝国の支配下では」という書き出しから続くため、王朝史の帰結として08に残すのが自然である。09は別見出しで始まるイスラーム文化一般の分類・学問・文学・建築を担当し、08のムガル文化を重複させない境界を推奨する。

## 検査方法

`scripts/mughal-source-names.json` に原文から独立して抽出した人物・地域・王朝・出来事・集団・建物・作品などを場面別に記録した。`scripts/check-mughal-source.mjs` は、場面順、説明本文への登場、地図の地点・見出し・地域名・人物・建物・模式表示への登場、地点参照、地図範囲、原文外場面の除外を確認する。
