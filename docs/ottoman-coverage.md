更新版：v0.010（2026年9月6日）

## 対象と考え方

提供資料 sources/03_ottoman_empire.md の本文・年表・補足を基礎に、既存の07の20場面を維持しながら、地図の説明を69段階に分けた。対象は07のみ。他8教材は版の表記だけを更新する。

本文・見出し・まとめ・補足・見どころに出る地名、人物、集団、建物、制度の名前を登録し、少なくとも一つの説明で位置または関係を描く。別名・略称も同じ対象に結ぶ。本文は削って対応を省くのではなく、地図の説明を増やす。スルタンなどの一般的な称号は、その場面の君主・直属軍の説明で扱う。

名前を押すと対応する説明を一度再生して停止し、「続けて再生」で残りの説明を順に見る。範囲は色面、都市は印、人物・集団・建物は画像または役割の記号。移動は矢印、建設は下からの出現、小国家の分立は複数の拠点の出現、敗退・解体は図像や領域の弱まり、税・救援要請・法の関係は説明付きの点線で示す。名前の文字は最後まで読めるように残す。

## 位置と歴史上の区別

- アナトリア全体と西北部を別の範囲で示す。モンゴルの侵入、ルーム＝セルジューク朝の弱体化・解体、複数のベイリク、ソグートのオスマン朝を時間順に分ける。一度の戦いの直後にすべて成立したと描かない。冒頭の13世紀・13世紀後半・1299年頃を分け、制度の成立過程や後世の主張にも別の年代を表示する。
- 金角湾・ボスポラス海峡・二重城壁は、粗い世界地図とは別の模式図で示す。船は金角湾北岸の陸上を迂回して湾内へ入り、入口の鎖を海上から通過する経路にはしない。
- ハギア＝ソフィアはスレイマニエ＝モスクの画像を流用せず、大聖堂からモスクへの用途変更を記号の変化で表す。スレイマニエはスィナンとともに建設を表示する。
- ジギスムント、メフメト1世、ムラト2世、カール5世、フランソワ1世、スィナン、セリム2世、フェリペ2世、ソビエスキには、別人の肖像を当てず共通の人物記号を使用する。
- ムラト1世時代の軍制は銃兵の絵を流用せず、共通の軍人記号とする。後の火器歩兵は鉄砲の図で区別する。
- カイロからイスタンブルへ示すカリフ位継承は「後世の主張」であり、1517年の実際の譲位式と断定しない。共同体・徴税・法律などは、関係する拠点にまとめた制度の模式図として注記する。
- 領域の色や小国家の数・配置は模式的なもの。現代の国境や厳密な歴史国境ではない。北アフリカのバルバロスはアルジェ付近を基準とし、旧場面データの模式座標は使用しない。
- 本文の関連箇所は、ルーム朝の段階的な解体、イスタンブルの呼称、東アナトリアでの支配拡大、地中海での優位、ハンガリーの大部分の割譲が伝わる表現に調整した。04・06への参照番号も修正した。

位置・分立過程の補助確認：[OpenStaxのオスマンとモンゴル](https://openstax.org/books/world-history-volume-1/pages/17-1-the-ottomans-and-the-mongols)、[メトロポリタン美術館のアナトリア・セルジューク解説](https://www.metmuseum.org/de/essays/the-art-of-the-seljuq-period-in-anatolia-1081-1307)。スィナンの建築については [MITの建築史講義資料](https://ocw.mit.edu/courses/4-614-religious-architecture-and-islamic-cultures-fall-2002/pages/lecture-notes/sinan/) も参照した。

## 実装と検査

- `ottoman-storyboard.js`：対象の名前・別名・座標と、各説明の登場対象・移動・出現・弱まり・建設を定義。
- `ottoman-story.js`：説明単位の再生、名前からの移動、一時停止、再開、拡大を含む再再生を管理。説明間の地図移動も連続して見せる。
- `ottoman-symbols.js`：画像のない人物・集団・制度・建物の役割を示す共通の記号。
- `check-ottoman-storyboard.mjs`：20場面・69説明、登録済みの名前422か所、位置・経路・効果対象・画像・記号を検査。本文に登録済みの名前を追加して地図の説明を忘れると検査で停止する。新しい未登録の固有名は自動抽出できないため、編集時に必ず登録と原文の目視照合を行う。
- 公開前は `npm run build` を実行する。
- ブラウザーでは読み上げを無効化し、無音で確認。1440・800・390・320画素幅で全69説明の静止表示を確認し、本文の保持、登場対象、重なり・欠けを検査した。
- 1440・390・320画素幅で移動中1035回の表示を検査。一時停止・再開、選択した説明での停止、自動の説明送り、世界からの再再生、本文の名前からの移動（全20場面の212対象を個別に選択）、画面サイズ変更、連続した場面選択を確認した。
- 動きを抑える設定では各説明を手動で切り替え、結果を静止表示する。通常再生でも20場面の次のコマへは自動で進めない。
