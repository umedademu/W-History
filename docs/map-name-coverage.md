# 本文と地図の名称の表示確認

v0.049、2026年9月10日。全14教材221ページを対象とする。

## 修正の背景

従来の原資料との対応検査は、地図用の見出しや補足一覧も掲載対象に含めていた。その欄が非表示になった後も検査が通り、地図上に実際の名前が出ていないことを検知できなかった。原資料の照合は残し、実際の表示用名称を別に検査する。

03の12ページは原資料326ページの9世紀の地図に対応する。原資料の図中にある王朝名を説明した場面で、対応する原資料がない独立した文章ではない。原資料の並びと場面順は変更していない。sources内の資料も変更していない。

## 表示方法

- 見出しと本文にある登録済みの名称を、同じ場面の地名、人物名、建物名と照合する。非表示の見出し・補足一覧は表示済みと数えない。
- 不足する地理上の名前は地図へ追加する。既存の同名の位置を基にし、王朝と都の対応が決まっている場合は場面内の都などを優先する。03の12ページでは後ウマイヤ朝をコルドバ、イドリース朝をモロッコ、アッバース朝をバグダード、サーマーン朝を中央アジアへ対応させる。
- 民族・信仰・言語・制度など、一地点を示さない語は地図の下の見える凡例へ表示する。
- 地図上の別名が本文にない場合は本文にある表記を使用する。説明に必要な名前が地図だけにあった箇所は本文を補足する。
- 横幅に収まらない地名は折り返す。文字を省略しない。既存の地理図の拡大上限は維持する。

## 編集と確認

名称一覧は `public/map-name-catalog.js`、照合と表示計画は `public/map-name-coverage.js` に置く。新しい固有名詞を追加する際は名称一覧と位置または分類も更新する。名称の検出はこの一覧を基準とし、未登録語を自動で固有名詞と判断する仕組みではない。

`npm run check` は原資料との対応、地図の拡大上限、全221ページの表示用名称の双方向対応を確認する。非表示欄だけに名前がある場合や、長い王朝名に短い別王朝名が含まれる場合の検査も含む。

`npm ci` 後に `npm run check:browser` を実行すると、確認用サーバーとブラウザーを自動起動し、幅1280と390で全221ページを確認する。音声再生は無効化し、動きを減らす設定で最終表示を調べる。名前の欠落、本文にない名前、地図からのはみ出し、地図の文字同士の重なり、実行時エラーを検査する。オスマン編は位置説明を終えて本文が表示された状態で照合する。通常のアニメーションの全時刻を網羅する検査ではない。

Windowsの標準的な場所にあるChromeまたはEdgeを使う。別の場所にあるブラウザーは環境変数 `W_HISTORY_BROWSER` に実行ファイルを指定する。それ以外の環境ではPlaywrightのブラウザーを別途用意する。確認終了時は確認用サーバーとブラウザーを閉じる。

携帯幅で連続してページを送ったとき、地図が前ページと同じ高さに戻ると寸法変更の通知が発生せず、人物が非表示のままになる場合があった。配置領域を広げた後は再配置も予約し、同じ高さでも表示を確定する。表示検査は人物の表示が確定するまで待ち、確定しない場合も失敗とする。

## 今回の確認結果

原資料との照合と公開用検査は成功。全221ページを幅1280・390で検査し、追加で見つかった02の16ページと05の4ページの別名不一致を修正した。修正した2章は両幅で再検査し、最終的に名前の欠落・本文にない名称・はみ出し・地図文字の重なり・実行時エラーはいずれも0件。静的な表示計画では地理上の追加表示388件、所在地を持たない語の凡例275件を確認した。
