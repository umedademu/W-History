## 掲載と省略

第1章・第6章と同じ方針で、章扉、回の導入の見取り図、クローズアップ、合否の分かれ目、独立した比較表・整理図、地図内文字・吹き出し、＋αの補足、年号のツボ、次回予告を省略する。本文の因果関係・比較説明・文化史は省略しない。sources は参照専用で、内容識別値を検査する。

source-selection.json は全行を掲載または理由付き省略に分類する。空行・見出し・紙面番号も記録し、掲載行の欠落や重複を検査する。原文の紙面をまたぐ文章は editorial-plan.json の「+」で接続し、別の段落は空白区切りとして区別する。

## ページ構成

editorial-plan.json の各ページに題名と掲載行を明示する。文字数や句点による自動分割はおこなわない。導入とその答え、制度と負担、原因と帰結、本文末の短い補足を一緒に読むように全節を通読して構成した。reading-plan.json に原文段落と文字位置を保存し、生成時に全段落・全文字の順序と連続性を照合する。長い説明も途中の括弧や引用で切らず、学習上のまとまりを優先する。

## 地図との対応

通常本文と太字の国・都市・人物・建造物を通読して登録した。bold-name-review.json は太字語を一件ずつ分類し、制度・宗教・書名など所在地のない語との違いを記録する。太字になっていない古代中国史の主要人物・王朝・都市も登録する。一文字の王朝は一般語の「明らか」「周り」「新しい」「お金」などと区別し、列挙された宋・元・明・清・唐も落とさない。

人物は肖像ではなく共通の説明用記号を、建造物は共通の寺院記号を使用する。都市は現地や遺跡の概略位置、広域の国家・民族は関連する代表拠点に示す。河川と移動・遠征の線は地理的な関係を示す概略線であり、行軍路や過去の流路を精密に復元するものではない。地理図の共通拡大上限は外さず、周辺地域が分かる範囲を保つ。

紙面をまたぐ「悪いや／ツ」「宗族による秩序」「高句麗のツング／ース系」などを接続した。第9回の「豪族たちの協力で／頼りだから」など、原資料のつながりに違和感がある箇所も補筆しない。神話の伏羲・神農・黄帝・堯・舜・禹には人物の所在地を割り当てない。殷墟や長安など、実在する遺跡・都市で文明の位置を示す。

「武帝」は前漢を基本とし、司馬炎の説明では洛陽へ切り替える。「文帝」は曹丕の説明では洛陽へ切り替える。戦国の魏と三国の魏、春秋の呉と三国の呉も本文に応じて拠点を変える。隋・唐の都は長安に共通するため、同じ地点に異なる呼称が重なる場合がある。

朝鮮四郡のうち玄菟・臨屯・真番には移転や位置比定の議論があるため、都市の点ではなく朝鮮半島の概略地域としてまとめて示す。南海・桂林・象郡、六都護府も領域の厳密な線は描かない。大雲寺は各州の寺院の総称なので、唐の政治中心地に説明用記号を置く。
