# 古代東アジア世界の人物・建物・道具の画像と演出（第3章）

v0.075（2026年9月）。第6章・第1章・第2章と完全に同一の高品質な3〜4頭身レトロドット絵スタイルへ統一。
第3章の全107場面において簡易図形（SVG）のフォールバックを完全撤廃し、登場人物および歴史的建造物・道具をすべて個別制作の透過PNG画像へ移行。あわせて、移動・進軍アニメーションおよび戦闘・対決・感情変化演出を実装。

## 保存先

すべて `public/images/ancient/` に保存。人物は128×192画素、建物・道具・乗り物は192×192画素の透過PNG。
単色背景（マゼンタ `#FF00FF`）による精密な境界透過処理を行い、白い服や髭、石碑、大理石などの白を損なうことなく、白枠や余白のゴミを完全に除去。

## 演出仕様

1. **行軍・遠征ルート連動（`route`）**:
   - 張騫の西域への旅、衛青・霍去病の匈奴遠征、法顕のインド巡礼、玄奘の天竺への旅、煬帝の大運河巡幸と高句麗遠征などで、キャラクターが滑らかに移動し歩行アニメーションを実行。
2. **主要戦闘の対決演出（`battle` / `targetActor`）**:
   - 牧野の戦い（武王 vs 紂王）
   - 垓下の戦い（劉邦 vs 項羽）
   - 白登山の戦い（劉邦 vs 冒頓単于）
   - 赤壁の戦い（孫権・諸葛亮 vs 曹操）
   - 淝水の戦い（東晋軍 vs 苻堅）
   - 安史の乱（玄宗 vs 安禄山）
   - 黄巣の乱（唐軍 vs 黄巣）
3. **勝敗・感情変化（`afterImage`）**:
   - 牧野での紂王の敗北、垓下での項羽の自刃（`chinese-defeated`）、赤壁での曹操の敗走、淝水での苻堅の敗走（`chinese-retreat`）へ動的に切り替わり。
4. **歴史的台詞の吹き出し演出（`bubble`）**:
   - 孔子「仁と礼による徳治政治」、孟子「性善説と王道政治」、老子「無為自然」、始皇帝「天下統一」、項羽「力抜山兮気蓋世」、劉邦「大風歌」、諸葛亮「出師表」、張角「蒼天已死黄天当立」など、歴史的名言を吹き出しで動的表示。
