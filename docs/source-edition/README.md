# 原文本文と装飾の再現

v0.050（2026年9月10日）。全14教材155ページ。

## 本文

参照専用のsources内5資料から、各節の本文104段落を抽出した。章の導入の見取り図、クローズアップ、比較表とその注記、地図、吹き出し、＋α、年号まとめ、次回予告は本文に混ぜない。本文の言葉と順序は保持し、文の切れ目でページを分ける。03・04の分割は前版の7・9ページを維持する。

paragraphs.json は段落の原文ファイル・行・紙面・画像・本文を記録し、page-plan.json はページへの分割位置と地図の対応を記録する。見出しと地図の表示は本文の内容に限定する。

## 装飾

Antigravity CLI経由のGemini 3.8 Flash (High)で、本文のある30画像を実際に読み取った。装飾の判定には書き起こしの見た目を使わない。通常文字とは別に、本文には赤太字と黒太字の2種類を確認した。括弧・書名の括弧は文字そのものとして保持し、別の装飾種類には数えない。本文の下線・斜体は今回の画像確認では報告されていない。

- 赤太字：明るい画面では濃い赤茶、暗い画面では明るい赤系の太字。
- 黒太字：各画面の本文色の太字。
- 読み仮名：画像で確認した親文字と読みを、その出現箇所に表示する。

同じ語を全箇所で一律に装飾しない。decoration-1.json〜decoration-5.json に、段落内の文字列・出現回数・装飾種別を記録する。小さい感情イラスト、紙面の柱、ページ番号の図形は本文の文字装飾ではなく、今回の再現対象に含めない。最終的な改ページの再確認はcross-page-review.jsonに記録した。初回確認のnotesにある未確認箇所は、この再確認で解消済み。
