# 08・09の説明順の照合

v0.019（2026年9月6日）。08「ムガル帝国」は343〜346頁、09「イスラーム文化」は347〜348頁の写真と書き起こしを並べて確認し、教材の大きな流れをそろえた。

## 08 ムガル帝国

前半はバーブル、フマーユーン、アクバル、ジャハーンギール、シャー＝ジャハーン、アウラングゼーブの順に王朝史を進める。アクバルの宗教融和の直後にカビールとナーナクを置き、その後でマンサブダール制を説明する。

アウラングゼーブ期は最大領土、厳格なスンナ派政策、シヴァージーとシク教徒の抵抗、地方政権の自立、英仏の植民地争奪戦と東インド会社の政治進出へ進む。王朝史の途中に挟まっていたムガル絵画とウルドゥー語はその後へ移し、インド産綿布の交易、王朝の終わりへつなげる。

## 09 イスラーム文化

最初に「固有の学問」と「外来の学問」という分類を示す。固有の学問では経典・アラビア語・神学・法学、歴史学、ガザーリー、イブン＝バットゥータを扱う。外来の学問では哲学・医学・数学・天文学・光学・化学を扱い、12世紀の西ヨーロッパへの翻訳で結ぶ。

その後はフィルドゥシー、ウマル＝ハイヤーム、サーディー、『千夜一夜物語』の文学へ進み、最後にモスク建築、アラベスク、細密画と工芸を扱う。

`scripts/check-mughal-culture-order.mjs` は場面の順序を固定し、インド産綿布、ガザーリー、サーディーなど、流れを支える語が本文から抜けていないかを検査する。
