原書15〜40ページの書き起こしを参照専用として読み込む。通常本文は原文の順番と語り口を保ち、長さによる自動分割や要約をせず、話のまとまりで分けた。紙面をまたぐ段落を接続し、元のページ・行番号と各場面の対応を残す。太字、色、下線、読み仮名は原文の記録を使用する。従来巻の第1章の重要語を近代・現代へ当てはめない。原文の誤記らしい表現もそのまま保持する。

各場面の「原文の図表・補足」で、関係する原書ページの全文を表示する。本文と重なる部分、図表内の文字、独立した囲み、吹き出し、ショパンのコラム、年号欄、欄外も含む。最初の場面から章扉15ページと回扉16ページを参照でき、全26ページへ到達できる。本文が「次ページの図➡P.30」のように別ページを指す場合は、その参照先も補足へ含める。原文の図表の文字情報を表示し、原画像にある地図の正確な領域や絵画そのものは再現しない。

地図は共通の世界地図と `public/map-camera.js` を使用し、最低32度の経度幅・24度の緯度幅を維持する。本文に出る地名・人物名を、近代・現代専用の名称表で選ぶ。人物は本文に関係する地点の絵で示し、正確な所在や全活動範囲を断定するものではない。地図文字は共通の配置処理で重なりを避け、表示位置を動かした場合は地点へ細い線を結ぶ。絵の姓名と同じ印の名前は一度だけ表示する。

新規89点は、実在の人物40人、同じ人物の別の姿5点、一般集団25点、建物・道具19点。既存の建物3点と合わせて92点を使用する。すべて透過画像として公開フォルダへ保存し、他人の絵の単純な色替えで人物を増やさない。古い教材の画像は上書きせず、比較に登場するナポレオン1世・ルター・ワシントン・ハンニバルなどもこの教材用の姿を用意した。

本文の後の55場面の模式欄で、会議の参加者、社会階層、革命の勢力や制度を見比べる。地図の同じ都市へ人物を密集させず、本文の読み始めを長い絵の欄で押し下げない。過去の比較・回想と次回予告は当時の当事者と分ける。吹き出しと図の注釈は「説明」として本文の意味を補い、史実上の本人の発言として引用しない。

原文にある独立運動・介入・亡命では人物や一般の軍を概略の経路へ結び付ける。シャルル10世・ルイ＝フィリップ・メッテルニヒ・ルイ＝ブランは失脚や亡命に応じて姿を変え、ルイ＝ナポレオンは皇帝になった後の姿へ切り替わる。通常の動きと、端末の動きを減らす設定の両方に対応する。場面を変更すると前の動きは止まり、地図から再表示できる。配置と生成の記録は [第1回の表示計画](modern-lesson-01/visual-plan.json) と [画像の制作記録](modern-lesson-01/image-assets.json) に残す。

七月革命・二月革命・ドイツ統一方式の対立は、原文に沿う模式図を併用する。七月革命はシャルル10世の反動政治に対する反発と、革命後の七月王政成立・共和派の政治参加排除を分ける。農民の政治派閥は補わない。二月革命は原書34ページの中小資本家・労働者・農民の関係を示す。大小ドイツ主義は原書38ページの統一方式を比較する。各図は対応する場面へ固定して表示する。

章・回の番号は巻ごとに独立する。既存の教材の識別名・順番・旧入口を保持し、追加教材には `modern-c01-l01-p01` など別の識別名を付ける。教材末尾は同じ巻の次の節へ進み、現在の近代・現代の最後からはその巻の一覧へ戻る。未実装の第2回へリンクしない。近代・現代では場面を進めた番号をURLへ保存し、再読込しても同じ場面を表示する。同じ教材内の場面リンクや、番号変更後の戻る操作にも表示を合わせる。

`docs/catalog/summary.json` の最上位の数は公開教材全体の合計。`collections` に各巻の集計を置き、既存の `chapters` は古代・中世・近世の章一覧として維持する。原書のページ数と、アプリの場面数は別に扱う。

生成は `node scripts/build-modern-lesson-01.mjs` と `node scripts/build-book-library.mjs`。通常の `npm run check` は原文の照合も行い、公開用の `npm run build` は保存した対応記録を基準に検査する。原文ファイルを公開環境へ送らずに検査できる。
