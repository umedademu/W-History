# 近代・現代の公開教材

v0.110では、トップページで「古代・中世・近世」と「近代・現代」を切り替え、後者の第1回「ウィーン体制とその崩壊」を公開した。5節・63場面を追加し、従来の128パート1013場面と合わせて133パート1076場面となる。

| 節 | 内容 | 場面数 |
| --- | --- | ---: |
| 1 | ウィーン体制の成立 | 9 |
| 2 | ウィーン体制の動揺 | 7 |
| 3 | ラテンアメリカの独立 | 10 |
| 4 | 七月革命とその影響 | 14 |
| 5 | 1848年革命（二月革命とその影響） | 23 |

原書15〜40ページの書き起こしを参照専用として読み込む。通常本文は原文の順番と語り口を保ち、長さによる自動分割や要約をせず、話のまとまりで分けた。紙面をまたぐ段落を接続し、元のページ・行番号と各場面の対応を残す。太字、色、下線、読み仮名は原文の記録を使用する。従来巻の第1章の重要語を近代・現代へ当てはめない。原文の誤記らしい表現もそのまま保持する。

各場面の「原文の図表・補足」で、関係する原書ページの全文を表示する。本文と重なる部分、図表内の文字、独立した囲み、吹き出し、ショパンのコラム、年号欄、欄外も含む。最初の場面から章扉15ページと回扉16ページを参照でき、全26ページへ到達できる。本文が「次ページの図➡P.30」のように別ページを指す場合は、その参照先も補足へ含める。原文の図表の文字情報を表示し、原画像にある地図の正確な領域や絵画そのものは再現しない。

地図は共通の世界地図と `public/map-camera.js` を使用し、最低32度の経度幅・24度の緯度幅を維持する。本文に出る地名・人物名を、近代・現代専用の名称表で選ぶ。人物名は本文に関係する代表地点の印であり、正確な所在や全活動範囲を表すものではない。地図文字は共通の配置処理で重なりを避け、表示位置を動かした場合は地点へ細い線を結ぶ。

七月革命・二月革命・ドイツ統一方式の対立は、原文に沿う模式図を併用する。七月革命はシャルル10世の反動政治に対する反発と、革命後の七月王政成立・共和派の政治参加排除を分ける。農民の政治派閥は補わない。二月革命は原書34ページの中小資本家・労働者・農民の関係を示す。大小ドイツ主義は原書38ページの統一方式を比較する。各図は対応する場面へ固定して表示する。

章・回の番号は巻ごとに独立する。既存の教材の識別名・順番・旧入口を保持し、追加教材には `modern-c01-l01-p01` など別の識別名を付ける。教材末尾は同じ巻の次の節へ進み、現在の近代・現代の最後からはその巻の一覧へ戻る。未実装の第2回へリンクしない。近代・現代では場面を進めた番号をURLへ保存し、再読込しても同じ場面を表示する。

`docs/catalog/summary.json` の最上位の数は公開教材全体の合計。`collections` に各巻の集計を置き、既存の `chapters` は古代・中世・近世の章一覧として維持する。原書のページ数と、アプリの場面数は別に扱う。

生成は `node scripts/build-modern-lesson-01.mjs` と `node scripts/build-book-library.mjs`。通常の `npm run check` は原文の照合も行い、公開用の `npm run build` は保存した対応記録を基準に検査する。原文ファイルを公開環境へ送らずに検査できる。

画面の確認は `npm run check:modern:browser`。読み上げと音声を開始前に無効にし、全63場面を幅1280・390、ライト・ダークの両方で確認する。本文・装飾・地図名の対応、文字の重なりと端からのはみ出し、拡大上限、全原書ページの補足、三つの対立図、巻の切替と保存、前後移動・再読込・末尾・旧教材の両端を検査する。本文の抽出と地理の詳しい対応は [第1回の記録](modern-lesson-01/README.md) を参照。

2026年10月3日の確認では、全63場面の計252回表示と、既存128教材の幅2種類での移動検査が通過した。経路をカルボナリの場面へ移した最終差分は、対象2場面を幅2種類・明暗両方の追加8回で確認し、ドイツ学生運動には経路がなく、カルボナリにはオーストリアからナポリ・ピエモンテへの介入2本が表示されることを確認した。別担当が原書26ページ全文の表示文字と三つの対立図を独立に照合した。原文資料60ファイルと、既存の未確定ファイル2件は作業開始時の内容を保った。
