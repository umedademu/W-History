# ドイツ帝国の政治制度の原文対照

原文89ページ538行は、帝国議会の権限について「予算審議権や質問権だけ」と説明している。この字句を含め原文資料、保存済み全行記録、学習本文は変更しない。

追加の制度図では「皇帝が宰相を任命する」「宰相は議会の信任に依存しない」「責任内閣制を認めない」を中心にし、議会に権限が全くなかったと断定しない。男性普通選挙があることと、議会の信任によって内閣が存立することは別の仕組みとして示す。

ドイツ連邦議会が公開する1871年憲法の説明では、第5条に連邦参議院と帝国議会による立法を、第15条に皇帝による宰相の任命を示している。原文の省略を校訂するのではなく、追加の図で政治制度の関係を補うための対照情報とする。

- [ドイツ連邦議会：1871年憲法の連邦参議院と第5条](https://www.bundestag.de/parlament/grundgesetz/1871-bundesrat-641300)
- [ドイツ連邦議会：1871年憲法の政府と第15条](https://www.bundestag.de/parlament/grundgesetz/1871-bundesregierung-641266)

2026年10月3日確認。追加図の記載例は「立法には連邦参議院と帝国議会が関わる」「皇帝が宰相を任命し、宰相は議会の信任に依存しない」。原文の全文と、追加説明の根拠を区別して参照できるようにする。
